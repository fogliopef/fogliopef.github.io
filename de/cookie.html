Cookies

FoglioPEF ist eine statische Website auf GitHub Pages. Sie setzt keine Cookies, weder technische noch Profiling-Cookies, und nutzt keine Analysewerkzeuge und keine Tracking-Cookies. Es gibt kein Cookie-Banner.

GitHub Pages kann, wie die Kopie auf Cloudflare Pages, technische Verbindungsdaten wie die IP-Adresse in Protokollen speichern, die für Betrieb und Sicherheit nötig sind.

Falls die Website später nicht notwendige Cookies verwenden sollte, wird diese Seite vorher aktualisiert.
